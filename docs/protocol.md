# 通信协议（netlock-state/1）

极简设计：**一个 GET + 一个 POST**，都是局域网明文 HTTP（完整性由签名保证，不依赖传输层加密）。

## 1. 学生机 → 教师机：`GET /api/state`

教师机返回当前"期望状态"（JSON）。**没保存过设置时返回 503**（学生机什么都不做，按本地缓存继续）。

```json
{
  "format": "netlock-state/1",
  "version": 12,
  "maskOn": true,
  "dns": ["10.46.254.10", "223.5.5.5"],
  "maskPasswordHash": "pbkdf2-sha256$100000$<saltB64>$<hashB64>",
  "sig": "<hex>"
}
```

### 签名（必须）

```
payload = version + "|" + (maskOn ? "1" : "0") + "|" + join(dns, ",") + "|" + maskPasswordHash
sig     = hex( HMAC-SHA256(连接密钥, payload) )
```

- 连接密钥 = 教师端生成的 32 字节随机数，随**配对文件**发给学生机（或由同一口令 PBKDF2 派生）。
- 学生机**验签不过一律拒收**并保持现状。这一条是这个功能自带的安全底线：不签名的话，
  同一网段里任何人都能冒充教师机把学生机 DNS 改成任意地址（把人引到钓鱼站）。
- `sig` 覆盖 `version`，所以"改大版本号"也会导致验签失败。

### 版本与防重放

- 教师端**每次保存 version +1**（不重用）。
- 学生机只接受 `version` **严格大于**自己已应用的值（`Protocol.IsNewer`），否则丢弃 → 重放旧状态无效。

## 2. 学生机 → 教师机：`POST /api/report`（每 10 秒）

```json
{ "machine": "PC-11", "appliedVersion": 12, "dns": "10.46.254.10",
  "nic": "以太网", "maskShown": false, "error": "" }
```

教师端用它显示"谁已生效 / 谁还没跟上"（`已应用版本 ≥ 当前版本` = 已生效）。
字段都做长度截断（machine ≤64、dns ≤128、nic ≤64、error ≤128），body ≤4 KB，单 IP 限速 200 次/秒。

## 3. 本地语义（不在协议里，但决定了行为）

| 项 | 规则 |
|---|---|
| 断网判据 | **只看有线物理网卡**（排除蓝牙 PAN / 虚拟网卡 / Wi-Fi Direct / WAN Miniport 等，见 `WiredNic.IsVirtualOrWireless`）：网卡 Down、无 IPv4、`0.0.0.0`、`169.254.*` 都算"没网"；**没有任何有线网卡时"不判定"（不弹遮罩）** |
| 确认时延 | 连续 5 秒没网才弹遮罩（避免交换机抖动误报） |
| DNS 应用范围 | 只写**有线且已启用**的网卡；不动无线/热点（否则会把热点客户端带进校园 DNS） |
| DNS 应用时机 | 收到新版本**同一轮内**执行；且只在"期望值 ≠ 网卡当前值"时执行（不每 2 秒刷一次） |
| 老师解除 | 口令本地校验（PBKDF2 散列）→ 写 `mask-ack.txt`（`时间戳|HMAC(连接密钥, "mask-ack|时间戳")`）→ 服务读它并**在本次断网期间不再弹**；网络恢复后清除 |
| 遮罩开关来源 | 本地缓存（离线也照旧工作）；教师机下发后覆盖 |
